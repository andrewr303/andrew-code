Hand a work brief to the fusion sidekick — your cost-efficient execution partner on a separate, persistent model. Write the brief as goal + constraints + success criteria; it explores, implements, runs tests, and reports back. The sidekick resumes across calls (its context persists and stays cache-friendly), so brief it like a colleague mid-project, not a new hire. If it is still mid-handoff, your brief is injected into its running session. Use it for mechanical implementation and verification; keep the plan, ambiguity interpretation, and final review for yourself. Pass fresh=true only when its accumulated context is a liability.
