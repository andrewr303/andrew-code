Drive a real debugger. Launch or attach a debuggee through a DAP adapter (debugpy for Python, lldb-dap/gdb for native, dlv for Go), set breakpoints, then step and inspect: stack_trace reads the frames, scopes/variables read locals, evaluate runs expressions in the paused frame. Sessions are named and persist across calls — typical flow: launch(stop_on_entry=true), set_breakpoints, continue, then stack_trace + variables after each stop. A C binary segfaulting, a wedged Python process, a hanging Go service: attach and read the state instead of sprinkling print statements.
